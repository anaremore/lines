#
# Official sources only: the agencies' own published schedules. No other site.
#
# Directives:  release <key>      starts a release; key is [a-z0-9-]+, unique
#              name <text>        short name shown in the UI ("CPI")
#              agency <text>      who publishes it
#              importance high|medium|low
#              affects <SYMBOL>…  catalog product symbols it moves (blackouts apply to these)
#              coverage <from> <through> verified|unverified
#                                 dates the list is complete for; outside them the calendar is
#                                 "missing" for this release, never assumed clear
#              source <url>       at least one
#              YYYY-MM-DD HH:MM verified|unverified <label>
#
# VERIFICATION STATUS (2026-11-07):
#   BEA  verified: dates and times read directly from the BEA schedule page's table.
#   FOMC dates verified from the Federal Reserve's FOMC calendar page; the 14:00 statement time
#        is the Fed's standing practice and is not printed on that page, so lines are unverified.
#   BLS  unverified: bls.gov refuses automated downloads (HTTP 403); the rows were read through a
#        text extraction of the BLS schedule pages, not compared by a person. To verify, open each
#        source in a browser, compare, and flip `unverified` to `verified` per line.
# BEA's page lists 2026 only; 2027 BEA releases are not published yet, so BEA coverage ends
# 2026-12-31 and the calendar reports BEA missing after that until this file is updated.
