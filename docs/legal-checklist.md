# Legal checklist (owner)

To complete **before roadmap 12, the first live connection**, ideally with a lawyer. This is a checklist, not legal advice.

- [ ] **Risk disclosure** shown on first run and in About: futures trading risk, losses can exceed deposits, simulated (paper) results are not indicative of live results.
- [ ] **"Not investment advice"** statement for indicators, journal analytics, and any future AI features.
- [ ] **Terms of use / EULA** for distributed binaries, consistent with FSL-1.1-ALv2 (`LICENSE.md`): warranty disclaimer, limitation of liability for software faults (e.g. missed or duplicated orders), user responsibility for orders sent.
- [ ] **Privacy notice:** what is stored locally (settings, journal, market-data cache), what is ever sent (opt-in crash reports/telemetry only), no selling of data.
- [ ] **Paper vs live labelling** reviewed (decision 0006): unmistakable, not colour-only.
- [ ] **Vendor requirements:** Rithmic/CQG conformance terms, required notices, app-name display, data attribution, and professional/non-professional status handling (usually the broker's, confirm).
- [ ] **Exchange data rules:** no redistribution of licensed data, including via plugins (0007), screenshots, or shared recordings (0010).
- [ ] **Prop-firm rule presets** labelled as user-editable approximations, not official firm rules (0006).
- [ ] **Third-party licences** shipped with every binary (`THIRD_PARTY_LICENSES`, in progress on PR #2).
- [ ] **Trademark check** on the name "Lines" and the icon before any public marketing.
- [ ] **Business entity** for vendor agreements and the copyright line in `LICENSE.md`.
